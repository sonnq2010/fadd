# Design System Theme Extensions and Lint Enforcement

Mobile application uses Flutter `ThemeExtension` to expose Design System tokens (`AppColors` and `AppTypography`) through `context.colors` and `context.typography`, keeping styling strictly aligned with Figma specifications across light and dark modes. Direct calls to `Theme.of(context).colorScheme` and `Theme.of(context).textTheme` are disallowed across feature code to prevent visual regressions and inconsistent theming; a custom analyzer plugin (`app_lints` powered by `custom_lint_builder`) flags these violations as compile-time errors in the IDE and fails `make verify` in CI. For platform widget compatibility, `AppColorScheme` uses `ColorScheme.fromSeed` to compute full Material 3 tonal containers while explicitly overriding core Figma brand, surface, and outline roles and disabling Material 3 elevation tint (`surfaceTint: Colors.transparent`).
